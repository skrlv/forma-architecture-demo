# ФОРМА — архитектура повседневности

Завершённый демонстрационный сайт вымышленного архитектурного бюро на русском языке. Статический HTML/CSS/JavaScript без зависимостей, внешних шрифтов, API и серверной обработки.

- Публичный сайт: https://skrlv.github.io/forma-architecture-demo/
- Репозиторий: https://github.com/skrlv/forma-architecture-demo

## Возможности

- Шесть архитектурных концепций, фильтры по типу проекта.
- Карточки с подробностями в нативном диалоге; переход к следующему и предыдущему проекту, Escape и закрытие по фону.
- Адаптивная навигация, раскрывающиеся этапы работы.
- Демо-бриф с проверкой полей и скачиванием текстового файла. Данные остаются в браузере, заявка не отправляется.
- Поддержка клавиатуры, reduced motion и размеров от 320 px.
- Все изображения находятся в `assets/`; относительные пути совместимы с GitHub Pages.

## Локальный просмотр

Из папки проекта запустите:

```sh
python3 -m http.server 4180
```

Откройте `http://localhost:4180`. Сборка и установка пакетов не нужны.

## Ограничения демонстрации

Бюро и проекты вымышлены. Изображения иллюстрируют настроение концепций; сайт не приписывает их авторство реальному бюро. Нет реальных заявок, оплаты и отправки персональных данных.

Источники изображений: [ASSETS.md](ASSETS.md).
